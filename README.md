# 공정·품질 통합 관리 시스템 (1단계)

자동차·금속가공 제조공정을 대상으로 한 **회사 내부용** 공장 공정·품질 통합 관리 웹 애플리케이션입니다.
1공장 실시간 조감도를 중심으로 설비 위치·현재 작업제품·생산수량·설비상태·품질점검 결과·트레블러 PDF·생산 분석·
생산 시뮬레이션을 하나의 화면 체계로 연결합니다.

> 현재는 **1단계(프런트엔드 프로토타입)** 구현입니다. 로그인·서버 DB·사진/PDF 서버 저장소·OCR 자동인식은
> 2단계에서 구현되며, 자세한 로드맵은 앱 내 **시스템 설정** 메뉴에서 확인할 수 있습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속. 별도 설치 없이 사내 여러 사용자가 같은 주소로 접속하는 것을 전제로 설계되었습니다.

## 기술 스택

- Next.js (App Router) · React · TypeScript
- Tailwind CSS
- Recharts (차트)
- 브라우저 `localStorage` (2단계에서 PostgreSQL 등 서버 DB로 교체 예정)

## 데이터 신뢰성 표기 원칙

이 시스템은 실제값·현장 추정값·시뮬레이션값·예시 데이터를 항상 색상 + 텍스트 라벨로 구분해 표시합니다
(`확정` / `현장 추정` / `가정 결과` / `입력 필요` / `검증 필요` / `예시 데이터`). 확인되지 않은 수치를 실제
분석결과처럼 표시하지 않는 것을 최우선 원칙으로 합니다. 자세한 내용은 앱의 **시스템 설정** 페이지를 참고하세요.

## 주요 화면

| 메뉴 | 설명 |
| --- | --- |
| 대시보드 / 1공장 | 실시간 조감도, 설비 상세패널, 설비사진 갤러리 |
| 품질 순회점검 | 점검 입력·이력·다음 점검대상 추천 (브라우저 저장) |
| 트레블러 관리 | PDF 업로드·수동 인식값 입력·고객사 자동분류·검증완료 표시 |
| 생산 분석 | 월 생산수량(현장 추정), 제작기간 분석(표본수 표기), 원인 후보 |
| 시뮬레이션 | 조건별 예상 생산수량 계산 (가정 실험, 실제 예측 아님) |

## 1공장 배치 안내

`src/data/zones.ts`에 실제 공장 배치(설비 위치·연결관계·통로 규칙)가 정의되어 있습니다. 설비 위치나 통로 구조를
변경할 때는 반드시 실제 현장 확인 후 수정하세요.
